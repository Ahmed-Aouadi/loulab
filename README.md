# لُولاب | Loulab

مساحة تعليمية عربية تفاعلية للأطفال في السنوات الأولى من التعلّم.

## التشغيل محلياً
افتح ملف `index.html` مباشرة في المتصفح. لا يحتاج المشروع إلى تثبيت حزم أو إعداد خادم أو مفاتيح API.

## النشر على Vercel
المشروع واجهة ثابتة (Static HTML/CSS/JavaScript):
1. اربط مستودع GitHub بمشروع Vercel.
2. اجعل Framework Preset على **Other** إذا طُلب منك الاختيار.
3. اترك Build Command وOutput Directory فارغين، أو استخدم إعدادات الموقع الثابت الافتراضية.
4. انشر الفرع `main` بعد دمج التغييرات.

وجود `index.html` في جذر المستودع يجعل الصفحة الرئيسية قابلة للاكتشاف مباشرة.

## المزايا
- مكتبة كتب عربية مع بحث وتصنيفات.
- قارئ كتب تفاعلي مع مؤشر تقدم.
- أسئلة متعددة الخيارات وتغذية راجعة فورية.
- مساحة رسم وتدريب على كتابة الحروف مع تنزيل العمل كصورة.
- قراءة صوتية اختيارية عند دعم المتصفح.
- مفضلة ونجوم وإنجازات محفوظة محلياً في المتصفح.
- تصميم متجاوب للهواتف والحواسيب.

## الخصوصية
لا يرسل التطبيق بيانات الطفل إلى خادم. التقدم والمفضلة محفوظان محلياً عبر `localStorage` على الجهاز نفسه.

> المحتوى تعليمي تمهيدي قابل للتطوير والمراجعة وفق المنهاج الدراسي المعتمد.
