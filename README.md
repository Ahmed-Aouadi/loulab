# نجمة — واحة التعلّم

تجربة تعليمية عربية للأطفال من 4 إلى 10 سنوات، مبنية من جديد انطلاقًا من موجز المنتج والنموذج الأولي المرفقين.

## التشغيل
- مشروع واجهة ثابتة بلا API إلزامي.
- افتح `index.html` أو انشر المستودع على Vercel باستخدام جذر المشروع.
- لا توجد خطوة بناء؛ نقطة الدخول هي `index.html`.

## التجربة الحالية
- ملفات أطفال محلية مع اختيار الفئة العمرية: صغار النجوم (4–6) وكبار النجوم (7–10).
- واحة العوالم الثمانية: الحروف، الأرقام، العلوم، الفنون، القصص، اللغات، القيم، والهدوء.
- نشاط الحروف: تتبع حرف ب، تمييز صورة تبدأ به، الأشكال الأربعة، وكلمة مشكولة.
- نشاط الأرقام: العد بالنقر حتى 5 أو 10 بحسب الفئة العمرية، والجمع بالتمر.
- نشاط علوم لترتيب نمو النخلة، تلوين، وقصة مصورة من ست صفحات.
- احتفال ونجوم وألبوم ملصقات وغرفة فنّوك وركن هدوء.
- لوحة ولي الأمر بعد ضغط مطوّل، مع إعداد الفئة العمرية وحد وقت الشاشة وتقليل الحركة.
- قراءة التعليمات عبر Web Speech API عند دعم المتصفح.
- حفظ محلي للتقدم والإعدادات، مع Service Worker لتخزين الصفحة الأساسية بعد أول زيارة.

## الخصوصية وحدود النسخة
- الملفات والنجوم والتقدم تبقى على الجهاز في `localStorage`. لا توجد حسابات حقيقية أو مزامنة سحابية.
- بوابة الوالدين بضغط مطوّل حاجز واجهة بسيط وليست مصادقة أمنية.
- الأصوات مولّدة من المتصفح وليست تسجيلات بشرية.
- التخزين دون اتصال يقتصر على ملفات التطبيق المخزنة؛ الخطوط الخارجية قد لا تتوفر دون إنترنت.
- الإعدادات الحالية تعرض حد وقت الشاشة وتذكير الاستراحة كإعدادات؛ لا يوجد بعد مؤقّت موثوق يوقف الاستخدام تلقائيًا.
- المحتوى نموذج أولي تعليمي، ويحتاج مراجعة تربوية واختبارات استخدام مع أطفال من الفئتين قبل الإطلاق العام.
