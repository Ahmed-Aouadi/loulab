# لُولاب — المنصة التعليمية

لُولاب مساحة تعليمية عربية للأطفال في السنوات الأولى من التعلّم، مع مكتبة تفاعلية، أنشطة، تحدٍّ يومي، إنجازات ولوحة متابعة لولي الأمر.

## التشغيل الحالي
- افتح `index.html` مباشرة أو انشر المستودع على Vercel كواجهة ثابتة.
- لا يلزم API لتجربة المكتبة والأنشطة.
- التقدم وملفات الأطفال محفوظة في `localStorage` على المتصفح والجهاز الحالي فقط؛ ليست حسابات موثقة ولا مزامنة سحابية.

## خصائص الواجهة
- مكتبة الكتب التفاعلية مع البحث والتصنيفات والقارئ.
- أسئلة اختيار متعدد، تصحيح فوري، نجوم وقراءة صوتية عند دعم المتصفح.
- مساحة رسم وتنزيل الرسومات.
- مساحة الطفل، تحدٍّ يومي، ألعاب، إنجازات وملخص تقدم لولي الأمر.
- ملفات متعددة للأطفال على الجهاز نفسه.

## قاعدة البيانات والحسابات
يوجد مخطط أولي في `supabase/schema.sql` لتأسيس:
- حساب ولي الأمر عبر Supabase Auth.
- ملفات المتعلمين المرتبطة بولي الأمر.
- محتوى تعليمي منشور.
- تقدم الطفل ومحاولات الأنشطة والإنجازات.
- سياسات Row Level Security لعزل بيانات كل أسرة.

### تفعيل المزامنة السحابية
1. أنشئ مشروعاً في Supabase.
2. نفّذ `supabase/schema.sql` في SQL Editor.
3. أضف تسجيل دخول ولي الأمر.
4. اربط الواجهة بـ `SUPABASE_URL` و`SUPABASE_ANON_KEY` عبر إعدادات النشر.
5. استبدل طبقة التخزين المحلي بعمليات القراءة والكتابة عبر Supabase واختبر RLS بحسابين منفصلين.

**مهم:** تسجيل الدخول الحقيقي والربط السحابي غير مفعّلين بعد. لوحة ولي الأمر الحالية محلية فقط. لا تضع مفتاح service-role في كود المتصفح.

## النشر على Vercel
استخدم جذر المستودع دون Build Command، واجعل نقطة الدخول `index.html`.


## إعادة التصميم — Atelier

تمت إضافة طبقة تصميم موحدة جديدة في `assets/loulab-atelier.css` وتطبيقها على الصفحات الرئيسية الأربع:
- `index.html`
- `library.html`
- `games.html`
- `dashboard.html`

الاتجاه البصري الجديد يستخدم خلفية ورقية دافئة، أخضر غابي، لمسات مرجانية وصفراء، وخطوط عربية أوضح. طبقة التصميم لا تستبدل منطق JavaScript الحالي أو بيانات الكتب والأنشطة؛ الهدف هو تحديث الواجهة مع إبقاء التجارب التفاعلية الحالية قابلة للاستخدام.
