# بُرعُم — نتعلّم.. ونكبر

منصّة تعلّم عربية للأطفال من **3 إلى 10 سنوات**: دروس وألعاب وحكايات ورسم، مع ركن مستقلّ لولي الأمر.
تطبيق ويب (PWA) ثابت بلا خطوة بناء، يعمل دون اتصال، **بلا إعلانات ولا تتبّع ولا حسابات ولا طلبات شبكة خارجية**.

## ما الموجود فعلاً (يُتحقَّق منه آلياً)
| | |
|---|---|
| الدروس | **195** درساً بمحتوى حقيقي (33 للفئة 3–4، 68 للفئة 5–6، 50 للفئة 7–8، 44 للفئة 9–10) |
| الأنشطة | **920** نشاطاً: اختيار، ترتيب، فرز، ذاكرة، تتبّع الحروف |
| المواد | لغتي، أرقامي، عالمي، ألسنتي (إنجليزية)، أفكّر، قيمي ومهاراتي، إبداعي، بلدي والعالم (7–10) |
| الألعاب | ذاكرة، فرز، من المختلف؟، سباق الحساب، ركّب الكلمة، مرسمي (رسم حرّ) |
| القصص | 6 حكايات بقراءة صوتية وسؤال فهم |
| التقدّم | نجوم (1–3)، ملصقات، 9 أوسمة، حديقة تنمو بنموّ التعلّم، مهام يومية ومراجعة |
| الأسرة | بوابة (رقم سرّي أو مسألة)، حتى 4 أطفال، حدّ يومي، استراحات، وقت نوم، قفل الترتيب، تقارير، تصدير/استيراد/حذف |

كل مسألة حسابية **تُولَّد وتُحسب بالكود** (لا تُكتب يدوياً)، ويفحصها `npm test`. الأسئلة ثابتة (deterministic) فلا تتغيّر بين زيارة وأخرى.

## التشغيل
```bash
npm start            # يخدم المجلد على http://localhost:8080
npm run check        # تدقيق المحتوى + الاختبارات
```
لا حاجة لـ `npm install` (لا اعتماديات). انشره على أي استضافة ثابتة؛ `vercel.json` يضيف رؤوس الأمان وسياسة CSP صارمة.

لإضافة درس: راجع `CONTENT_GUIDE.md`.

## حدود صريحة (يجب معرفتها قبل الإطلاق للجمهور)
- **المراجعة البشرية لازمة:** المنهج لم يراجعه معلّم متخصّص. الحقائق العلمية والتاريخية بسيطة ومتّفق عليها، لكن راجعها تربويّاً.
- **الصوت:** القراءة تعتمد على محرّك النطق في الجهاز. جودة العربية تختلف، وقد لا يوجد صوت عربي أصلاً. التسجيلات البشرية غير موجودة بعد.
- **التشكيل:** الحروف والحركات مشكولة بطبيعتها، أمّا نصوص القصص والفقرات فغير مشكولة (التشكيل الآلي غير موثوق).
- **الصور:** صور الدروس رموز إيموجي من خطوط الجهاز، فيختلف شكلها بين أندرويد وiOS وويندوز. الأيقونات والشخصية والنباتات SVG أصلية. استبدال الإيموجي برسوم مخصّصة تحسين مستقبلي.
- **الخطوط:** نظامية (لا خطوط خارجية حفاظاً على الخصوصية). لإضافة Cairo أو Baloo Bhaijaan 2 ضَع ملفاتها في المشروع وصرّح بها بـ `@font-face` محلّياً.
- **لا حسابات ولا مزامنة:** التقدّم على جهاز واحد في المتصفح. مسح بيانات الموقع يحذفه (يوجد تصدير/استيراد).
- **الرقم السرّي رادع منزلي لا حماية أمنية:** مخزّن مُجزَّأً (SHA-256) محلّياً، ومن يملك الجهاز وأدوات المطوّر يستطيع تجاوزه.
- **الخصوصية القانونية:** `PRIVACY.md` شرح بلغة مبسّطة، وليس نصّاً قانونياً. راجعه مع مختصّ (القانون الجزائري 18-07، COPPA، GDPR-K) قبل النشر التجاري.
