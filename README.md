# بُرعُم — نتعلّم.. ونكبر

منصة عربية RTL للتعلم المبكر للأطفال من 3 إلى 10 سنوات.

## تشغيل سريع
- افتح المستودع عبر GitHub Pages أو أي استضافة ملفات ثابتة.
- محلياً: شغّل خادماً ثابتاً من مجلد المشروع، مثل `python -m http.server 8000` ثم افتح `http://localhost:8000`.
- لا تستخدم فتح `index.html` مباشرة إذا أردت اختبار PWA؛ Service Worker يحتاج HTTP أو HTTPS.
- لا توجد عملية بناء أو حزم خارجية مطلوبة.

## الموجود في الإصدار
- واجهة عربية RTL متجاوبة مع الهاتف والحاسوب.
- 380 نشاطاً تعليمياً مولّداً من 10 مجالات × 38 نشاطاً، مع سؤال تفاعلي لكل نشاط.
- ألعاب قصيرة، أربع حكايات، نقاط وشارات.
- ملف طفل محلي وملخص تقدم وتصدير/مسح بيانات.
- Service Worker وWeb App Manifest للتثبيت والعمل دون اتصال بعد أول تحميل.
- هوية SVG أولية وألوان مركزية.

## البيانات والخصوصية
يُحفظ الملف والتقدم في `localStorage` على الجهاز الحالي فقط. لا توجد حسابات، مزامنة سحابية، تحليلات، أو إرسال بيانات إلى خادم. حذف بيانات المتصفح قد يحذف التقدم. لا تدخل بيانات شخصية حساسة.

## حدود يجب معرفتها قبل الإطلاق
هذا إصدار MVP تعليمي أولي وليس منتجاً تربوياً معتمداً أو خدمة إنتاجية متعددة المستخدمين. الأسئلة والخيارات في كتالوج الدروس أولية وبعضها يستخدم أنماطاً متكررة، ويحتاج مراجعة تربوية ولغوية واختبارات عمرية. لا توجد حتى الآن لوحة إدارة محتوى، حسابات أولياء الأمور، مزامنة، أو قاعدة بيانات. الصوت/النطق غير منفذ رغم زر كتم الحالة. يلزم اختبار الوصول، الأداء، التوافق، واختبار الأطفال بإشراف أولياء الأمور قبل النشر العام.

## هيكل المشروع
- `index.html` نقطة الدخول
- `app.js` منطق التطبيق والكتالوج والحالة
- `app.css` الواجهة المتجاوبة
- `sw.js` التخزين المؤقت والعمل دون اتصال
- `manifest.webmanifest` إعدادات التثبيت
- `brand/` ملفات الهوية
